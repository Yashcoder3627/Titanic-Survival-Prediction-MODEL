# 🚢 Titanic Survival Prediction

This project uses **Machine Learning** to predict whether a passenger survived the Titanic disaster.

## 🛠️ Technologies

* Python
* Pandas
* NumPy

## 🤖 Model

**Logistic Regression**

### Features Used

* Pclass
* Age
* SibSp
* Parch
* Fare

## 🔄 Workflow

Data Preprocessing → Feature Selection → Train-Test Split → Logistic Regression → Prediction → Accuracy Evaluation

## 📊 Output

The trained model predicts passenger survival and generates an `Output.csv` file containing:

* PassengerId
* Survived
